# Phase 21 screenshots

`before/` is the tree at the start of the phase (taken in step 1, before any style change); `after/` is the final tree. Both come from the same script,
`apps/web/e2e/shots.spec.ts` (`SHOTS_DIR=before|after pnpm exec playwright test e2e/shots.spec.ts`, fixtures build, dark scheme unless the name ends in `-light`,
1440x900 or 375x812, 1x scale to keep the repository small). Each name appears in both folders, so compare them by name.

Notes for the reader:

- Run-page pictures are viewport-sized: the run page is a fixed-height application page, so the document no longer scrolls (D15). `before/` full-page shots of the old page are taller.
- `before/run-evidence-1440.png` shows the timeline: the `?view=evidence` parameter did not exist yet. The fixture coding run has no artifact store, so `after/run-evidence-1440.png` is taken with artifact references added to the events response in the browser (`e2e/artifacts.ts`).
- `run-375-inspector-open` is a full-page capture of a scrolling document with a fixed overlay: the overlay fills the first screen (asserted by `design.spec.ts`) and the timeline shows below it only because the capture is taller than the viewport.
- Session-only pages (members, API keys, pricing, audit, sign-in with a real session, the real viewer-withheld run) are not in this set; their pictures are regenerated by the unchanged `auth-e2e` spec into `docs/screenshots/phase-15/` (see KI-121: not critiqued in this phase).

## Critique against the concepts (`docs/design/concepts/`)

What matches: the rail (brand, switchers, links), the 44 px top bar with breadcrumb and recording indicator, the instrument-style run header (title, status badge, retries tag, mono id line, one-sentence headline with the inline "Show it", one readout strip with amber retries and red errors), the
tab row with counts, the three-column work area (context | pane | inspector), the dense runs table with small-caps heads, segmented status toggles and the search box as a full-width command line, flush right inspector with small-caps section labels, one status grammar, IBM Plex everywhere, light and dark.

What differs from the concepts, and is known:

| Page | Critique |
| --- | --- |
| `dashboard-1440` | Reads as the same app: head with lede, readout strip, two dense tables with small-caps heads and one badge grammar. Plainer than the concept (no sparkline, no facet column) and the lower third of the page is empty with 12 runs. |
| `runs-list-1440`, `-search-1440` | Closest to the concept's table. The concept's left facet column and "REC · n running" count are not built (facets are a strip that appears only for searches, D13); the filter row is one line of segmented toggles. |
| `run-failed-1440` | Closest to `app-run-story`. Missing against the concept: a Findings column beside the story for runs that have none (the context column shows what exists), the "Compare" tab, and the top-bar search. |
| `run-failed-inspector-1440` | Inspector flush right with the first-error panel, condensed section labels instead of tabs (D8), resizable by drag. The context column stays open at this width (it folds to a labelled strip only below 1408 px, where the pane would drop under 480 px); the class chips wrap onto a second row in a narrow pane instead of scrolling under a fade. |
| `run-multiagent-waterfall-1440` | Waterfall keeps its own categorical palette (ADR-071); agent list clamped to two lines; tabs show counts for Timeline and Evidence only (a span count would force the waterfall derivation on every view). |
| `run-coding-story-1440` | One marker per story step (the number), tone shown by colour and words; the numbering column is small and muted, as in the concept. |
| `run-evidence-1440` | New view, a plain table of captured artifacts with an Open button per row; no content preview (the inspector loads content on request). |
| `compare-1440` | Two header cells (accent left bar for the left run, amber for the right), dense summary table, aligned list. Heavier than the other pages because it keeps the long ids. |
| `experiments-1440`, `experiment-detail-1440` | Dense list, tone-panel control banner. The creation form is a single 36 rem column with a wide empty right side. |
| `login-1440` | Centred card with the brand mark; intentionally outside the shell. |
| `*-375` | Rail becomes a strip, readouts an even grid with the tokens readout spanning two columns, tabs on one row, inspector a full-width overlay under the top bar. |
| `*-light` | Same layout; light surfaces are white on a grey canvas as in `app-light`. |
