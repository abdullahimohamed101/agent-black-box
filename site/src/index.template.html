Agent BlackBox

A flight recorder for AI agents. See what your agent did, why it failed and what it cost.

Add a few lines to an agent and every model call, tool call, shell command, file edit, retry and failure is recorded as a typed event, then shown as a run you can read from the top.

Install from source View the repository

What it is

When an agent misbehaves you usually have a log and a guess. Agent BlackBox records what the agent actually did, in order, and keeps it in a form a person can read: which model it called, which tools it ran, what a command printed, where it retried, where it stopped.

Agent concepts are typed in the event contract. A tool call is a tool call, not a line of text to search for, so the same record can drive the run page, the findings, the cost totals and an approval request.

What you get today

Runs and the fault line

Every run is a row with its status, duration and cost. A failed run shows the step where it first went wrong, marked with a single red line, so you start at the failure instead of scrolling for it.

Timeline and waterfall

Read a run step by step, with the inspector open on any call. For runs with several agents the waterfall gives each agent its own lane, so you can see who was waiting on whom.

Findings

Reliability findings such as a possible loop, a retry storm, a tool that keeps timing out, context growth and a cost spike, each pointing at the events that support it.

Cost

Tokens and cost per run, and cost and reliability across runs over time, so a change in a prompt or a model shows up as a number.

Policies and approvals

A policy can pause a tool call until a person approves it. The request, the decision and who made it are recorded with the rest of the run.

Privacy by default

  • Capturing prompts, tool inputs and command output is a setting you turn on, per project. The local development project that make seed creates turns it on; a project you create does not unless you choose it.
  • Secrets are redacted before events leave your process.
  • This page loads no script, font, image or stylesheet from any other site, and runs no JavaScript.

Works with

A Python SDK, and adapters for LangGraph, OpenAI, Anthropic and MCP. The adapters are tested offline; the project has not run them against live providers.

from blackbox import BlackBox

bb = BlackBox(api_key=..., project="coding-agent")
with bb.run("Fix OAuth timeout") as run:
    with run.span("run-tests", kind="shell"):
        agent.execute()

Quickstart: install from source

You need Python 3.12 with uv, Node 22 with pnpm, and Docker.

git clone {{REPO_URL}}.git
cd agent-black-box
cp .env.example .env
make setup    # Python and JS dependencies, Postgres, migrations
make up       # API, worker and web in containers
make seed     # a local workspace, project and development API key
make demo     # run the example agents and open their runs

Then open the dashboard on port 3000 of your machine. Sign-in here is for local development only. Setup notes cover the details and the roles.

Status

Pre-release software that you build and run yourself. Nothing is hosted, and there is no account to create. The development sign-in is not meant for a shared deployment.
